# 瑞士编辑 · Swiss Editorial Poster Skill

一张有戏「瑞士编辑」风格中文海报技能。9:16 竖版，主标题 + 短句 + 页脚，简洁可控。

A poster-generation skill for the **swiss editorial** style by 一张有戏 (EricChan): 9:16 portrait, Simplified Chinese, one headline, one supporting line.

## 使用 · Usage

填入字段即可生成一张海报（只给主标题也能用）：

```
【主标题】：
【短句】：
【场景】：
【版式】：
【主色强调】：
【画幅】：9:16
```

详见 [SKILL.md](SKILL.md)、[prompt.md](prompt.md)；示例见 [examples/themes.md](examples/themes.md)；完整样例提示词：[PROMPTS.json](PROMPTS.json)。小红书配文：[XIAOHONGSHU_COPY.md](XIAOHONGSHU_COPY.md)。
